# Hotel Aurora

Sitio web de un hotel desarrollado con React para la cátedra Lenguaje IV (Ingeniería en Informática, Universidad Católica de Salta).

## Características

- Catálogo con 4 habitaciones
- Navegación con React Router (Habitaciones, Nosotros, Contacto)
- Descarga de la reserva como archivo .txt usando Blob
- Diseño minimalista y responsive

## Cómo ejecutarlo

```bash
npm install
npm start
```

Se abre en http://localhost:3000
